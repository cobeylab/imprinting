# Show all WHO regions

Lists all WHO regions, with valid spelling and formatting.

## Usage

``` r
show_available_regions()
```

## Value

A data frame of valid region names.

## Examples

``` r
show_available_regions()
#> # A tibble: 6 × 1
#>   region               
#>   <chr>                
#> 1 eastern_mediterranean
#> 2 europe               
#> 3 africa               
#> 4 americas             
#> 5 western_pacific      
#> 6 southeast_asia       
```
